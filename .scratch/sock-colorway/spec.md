# Спека: конструктор расцветки носка

Нормативный контракт поведения страницы `/sock-colorway/` — по образцу [спеки мыска](../toe-calculator/spec.md).
Код, разошедшийся с ней, — баг кода; поведение меняют осознанно и правят спеку тем же коммитом.
На разделы ссылаются комментарии в коде, имена тестов и заголовки PR.

Опора — разговор с мастером 2026-11-19…20 и прототип на ветке `prototype/sock-colorway`
(`.scratch/sock-colorway/prototypes/colorway.html`, в `main` не мержится). Словарь — в корневом
[`CONTEXT.md`](../../CONTEXT.md). Research не нужен: конструктор не считает по вязальным формулам.

---

## 1. Назначение и область

Страница, где мастер собирает расцветку носка и перебирает варианты на глаз: набирает палитру,
раскладывает её полосами по участкам носка — руками или кубиком — и сразу видит носок целиком.
Цель — вдохновение и прикидка, а не выверенный расчёт. Главный сценарий — телефон; с компьютера
страница встаёт в две колонки (§9.1).

**Конструкция зафиксирована:** один носок cuff-down из пяти участков (§5). Пятка и мысок
нарисованы условно, их конструкция не выбирается.

**Считается в рядах.** Плотность, сантиметры и граммы — вне области (§13): в итоге стоят ряды
каждым цветом и их доля, дальше мастер подгоняет сам.

**Это конструктор, а не калькулятор** (`CONTEXT.md`): на витрине он стоит в третьем разделе
«Конструкторы».

## 2. Словарь

Эти слова идут в код, интерфейс и коммиты. Синоним значит разойтись со спекой. Источник истины —
`CONTEXT.md`; таблица его повторяет.

| Слово | Значение |
|---|---|
| **Конструктор** | страница, где вариант изделия собирают и перебирают на глаз, без расчёта |
| **Палитра** | набор из 1–6 цветов, из которых собирается расцветка |
| **Цвет N** | цвет палитры по его номеру: «цвет 1», «цвет 2». Не буквы |
| **Расцветка** | палитра, разложенная по носку: какие ряды каким цветом на каждом участке |
| **Участок** | резинка, паголенок, пятка, стопа, мысок; раскрашен последовательностью полос |
| **Полоса** | несколько рядов подряд одним цветом палитры внутри участка; идёт один раз |
| **Однотон** | участок из одной полосы |
| **Генерация** | перебор незакрытого замком: цветов палитры, полос носка или полос участка |
| **Замок** | отметка на цвете, участке или полосе: генерация её не меняет |
| **Мастер** | нейтральное существительное для того, кто вяжет |

**«Раппорт» здесь не используется**: повторяющегося рисунка в этой версии нет (§16).

## 3. Модель домена

```
Расцветка
├── палитра: Цвет[1..6]            — цвет: sRGB, замок
└── участки: [резинка, паголенок, пятка, стопа, мысок]
    └── участок: рядов ≥ 1, замок, полосы: Полоса[1..рядов]
        └── полоса: номер цвета, рядов ≥ 1, замок
```

**Инвариант:** сумма рядов полос участка равна рядам участка. Каждая операция §5.3 его сохраняет.

Из расцветки однозначно выводится **раскладка рядов**: для каждого ряда носка сверху вниз — его
участок и цвет; полосы участка идут подряд, участки — в порядке §5.1. Рисунок, развёртка и итог
строятся из раскладки и ничего не хранят сами. Ядро — чистый TypeScript без Vue (граница из
`CLAUDE.md`).

## 4. Палитра

- **От 1 до 6 цветов.** «+ цвет» добавляет сгенерированный цвет, различимый с остальными (§6.2),
  пока цветов меньше шести.
- **Цвет задаётся вручную** системным выбором цвета (`<input type="color">`). В десктопном
  Chromium у него есть пипетка по экрану — она достаётся даром и отдельно не делается.
- **Цвет называется номером** — «цвет 1» … «цвет 6». Номер — позиция в палитре; удаление цвета
  сдвигает номера следующих, полосы следуют за своим цветом.
- **Удаление цвета.** Нигде не используемый уходит сразу. Используемый — после подтверждения
  на странице, которое называет участки с этим цветом; его полосы становятся цветом 1.
  Последний цвет не удаляется. Без `window.confirm`: браузерный диалог блокирует страницу.
- **Готовые палитры.** Список именованных палитр по 2–4 цвета; выбор заменяет палитру целиком
  и снимает замки цветов. Полоса с номером цвета, которого в новой палитре нет, берёт цвет
  по кругу (номер по модулю размера палитры). Первая в списке — палитра по умолчанию (§8).

## 5. Участки и полосы

### 5.1. Участки

Сверху вниз: **резинка → паголенок → пятка → стопа → мысок**. Длины по умолчанию — условный
типовой носок; их правят (целое ≥ числа полос участка):

| Участок | Рядов |
|---|---|
| резинка | 20 |
| паголенок | 50 |
| пятка | 30 |
| стопа | 60 |
| мысок | 20 |

Длины к размеру не привязаны: связь со справочником набора петель и калькулятором мыска — вне
области (§13).

### 5.2. Полосы

Участок — последовательность полос, каждая идёт один раз. Однотон — участок из одной полосы.
Повторяющегося рисунка внутри участка нет (§13).

### 5.3. Правка полос

| Действие | Что происходит |
|---|---|
| **+ полоса** | новая встаёт в конец и берёт `round(рядов / (n + 1))`; предыдущие отдают ряды пропорционально своей длине (наибольший остаток, каждой ≥ 1). Цвет — следующий за цветом последней полосы по кругу палитры |
| **✕ у полосы** | её ряды уходят предыдущей (у первой — следующей). Последнюю полосу участка не удалить |
| **Число рядов полосы** | разницу забирает или отдаёт следующая полоса (у последней — предыдущая); обе ≥ 1 |
| **Тянуть край полосы** | граница между полосами i и i+1 сдвигается на целые ряды; обе ≥ 1 |
| **Тянуть полосу целиком** | как раздел на диске: длина полосы та же, левая соседка растёт, правая сжимается на столько же; упор — когда у соседки 1 ряд. Первая и последняя полоса целиком не двигаются — отдать ряды некому |
| **Поменять местами** | полосу перетаскивают в списке за ручку; цвет, длина и замок едут с ней |
| **Рядов в участке** | все полосы растягиваются или сжимаются пропорционально |
| **Цвет полосы** | выбор из квадратиков палитры |

Замок полосы защищает её только от генерации; руками закреплённую полосу править можно.

## 6. Генерация и замки

### 6.1. Замки

Замок есть у **цвета палитры**, у **участка** и у **полосы**. Закрытое генерация не меняет;
правка руками замком не ограничена.

### 6.2. Три кубика

| Кубик | Где | Что перебирает |
|---|---|---|
| **палитры** | в плашке палитры | незакреплённые цвета. Полосы не трогает |
| **участков** | в шапке дерева участков | полосы всех незакреплённых участков из текущей палитры. Цвета не трогает |
| **участка** | в строке участка | полосы только этого участка. У закреплённого участка неактивен |

**Цвета** — случайные, но **различимые**: заметно отличаются по светлоте и тону от остальных цветов
палитры, включая закреплённые, и палитра не выходит вся тёмной или вся светлой. Цветовой теории
нет (§13). Размер палитры кубик не меняет.

**Нарезка участка без закреплённых полос:** заново 1–4 полосы случайной длины (каждая ≥ 1),
соседние — разного цвета, если в палитре больше одного цвета. Резинка, пятка и мысок чаще однотон
и общим акцентным цветом; паголенок и стопа чаще 2–4 полосы. Кубик одного участка берёт акцент
у уже стоящих резинки, пятки или мыска, чтобы не выбиваться из носка.

**Нарезка участка с закреплёнными полосами:** число полос и их порядок сохраняются; закреплённые
остаются цветом, длиной и местом, незакреплённые получают новые цвета (по возможности не как
у соседей) и делят оставшиеся ряды заново.

**Палитра из одного цвета:** над носком подсказка, что полосы выйдут однотоном и стоит добавить
цвета.

## 7. История и сброс

- **История действий:** «Отменить» и «Вернуть» в плашке, с клавиатуры Ctrl+Z и Ctrl+Shift+Z
  (Ctrl+Y). Шаг истории — снимок расцветки до изменения; изменения, идущие подряд быстрее 400 мс
  (перетаскивание, набор числа), склеиваются в один шаг. Новое действие после отмены стирает
  «Вернуть». Пока фокус в поле ввода, сочетания клавиш остаются полю.
- **История живёт в памяти страницы** и в адрес не попадает (§10).
- **«Сбросить»** — без подтверждения: белый носок — палитра из одного белого цвета, все участки
  однотон цветом 1, длины по умолчанию (§5.1), все замки сняты. После сброса — плашка
  «Носок сброшен · Отменить»; сброс откатывается как любое действие.

## 8. Расцветка по умолчанию

Пустой hash открывает **двухцветный носок** — пример, который объясняет экран без слов:
палитра «синий + лён» (`#2f3e5c`, `#e8e2d4`); резинка, пятка, мысок — однотон цветом 1;
паголенок и стопа — однотон цветом 2; замков нет.

## 9. Экран

### 9.1. Раскладка

Телефон — одна колонка: носок, дерево участков, итог; плашка палитры прибита к низу экрана.
От 800 px — две колонки: носок слева и не уезжает при прокрутке, дерево и итог справа.

### 9.2. Носок

- **Вид «Носок / Развёртка»** — переключатель над рисунком, по умолчанию «Носок».
  **Развёртка** — носок прямой трубкой: все ряды сверху вниз, подписи участков и их рядов.
- **Рисунок только показывает:** тапа по носку нет, правят в дереве (§9.3).
- **Силуэт** — иконка «socks» (Alex Pour, коллекция «Men Outfit Line Vectors», SVG Repo,
  CC Attribution): паголенок отвесно, стопа вниз-влево, пятка — линза сзади, мысок — шапочка.
  **На странице обязательна подпись автора со ссылкой** — условие лицензии.
- **Ряды** — полосами поперёк направления вязания: резинка горизонтально; паголенок
  горизонтально, на изгибе веером, стопа поперёк себя; пятка — поперёк длинной оси линзы;
  мысок — поперёк стопы. Ряды одного участка — одной толщины; масштаб у участков свой — рисунок
  держит форму иконки, а не масштаб рядов.
- **Граница цвета** — по середине линий иконки: внешний контур сжат, внутренние края участков
  расширены на половину толщины линии; края сходятся без зазора, углы резинки прямые.

### 9.3. Дерево участков

- **Шапка дерева:** «Участки» и кубик участков (§6.2).
- **Строка участка:** раскрыть/свернуть, название, мини-полоска из его полос, число рядов,
  кубик участка, замок участка.
- **Раскрытый участок:** поле «рядов в участке»; крупная полоса участка с числом рядов на каждой
  части — края тянутся, средние полосы двигаются целиком (§5.3), закреплённая помечена замком;
  под ней список полос: ручка перетаскивания, квадратики цветов палитры, число рядов, замок, ✕;
  кнопка «+ полоса».

### 9.4. Плашка палитры

Внизу экрана: подпись «Палитра», кубик палитры, цвета (выбор цвета, номер, замок, ✕), «+ цвет»,
«Готовые ▾», затем «Отменить», «Вернуть», «Сбросить».

### 9.5. Итог

Ряды каждым цветом на весь носок с примерной долей: «цвет 1 — 84 ряда, ~40 %». Доля — целые
проценты. Граммов и метров нет: без плотности и пряжи они были бы выдумкой.

### 9.6. Замок на экране

Нарисованный навесной замок, не эмодзи. Закреплённый — белый замок на янтарной заливке, у цвета
палитры вокруг чипа янтарная рамка; незакреплённый — бледный, с открытой дужкой. Подсказка
говорит, что значит состояние: «Закреплено: генерация не меняет».

## 10. Хранение и ссылка

Расцветка целиком — палитра, участки, полосы, все замки — живёт в **hash** адреса, как
у калькуляторов: ссылкой делятся как есть. История (§7) в адрес не попадает. `localStorage`
конструктор не использует. Битый или неполный hash чинится дефолтом поля, а не отказом открыть
страницу (тот же подход, что §10.4 мыска); полосы, не сходящиеся в сумме с рядами участка,
подгоняются пропорционально (§5.3, «Рядов в участке»). Точный формат hash — решение реализации,
фиксируется в этом разделе вместе с ней.

## 11. Тесты

- **Ядро — Vitest:** раскладка рядов; каждая строка таблицы §5.3 и сохранение инварианта §3;
  нарезка с закреплёнными полосами; различимость сгенерированных цветов; уважение замков всеми
  тремя кубиками; готовые палитры и цвет по кругу; удаление цвета; сброс; история — склейка
  шагов, отмена, возврат; разбор и сборка hash, починка битого.
- **Страница — Playwright** (`functional`): кубики не трогают закрытое; удаление используемого
  цвета спрашивает; сброс откатывается «Отменить»; расцветка доезжает до адреса и
  восстанавливается из него; перетаскивание края, полосы целиком и перестановка — пальцем.
- **Скриншоты** — `screens`: носок по умолчанию, развёртка, белый носок после сброса. Генерация
  на скриншотах — только с фиксированным зерном случайности.

## 13. Вне области

Отложено отдельными тикетами:

- **страница вариантов**: много сгенерированных расцветок сразу, выбранная открывается по hash;
- **микрораппорт**: повторяющийся рисунок полос внутри участка;
- цветовая теория: гармонии палитры;
- пара носков, в том числе «носки-братья»;
- избранные расцветки;
- скачивание картинки;
- загрузка фото и снятие цветов с него;
- плотность, сантиметры, граммы и метры пряжи;
- связь с калькулятором мыска и справочником набора петель;
- выбор конструкции пятки и мыска;
- сквозной рисунок через несколько участков.

## 16. Отменённые решения

Записаны, чтобы не переоткрыть из истории прототипа (коммит `bae124e` и раньше на ветке
`prototype/sock-colorway`):

- **Общий раппорт и правила** (ровные, нарастающие, Фибоначчи, случайные) и **режимы участка**
  «однотон / в полоску», раппорт, продолжающийся через однотонные участки. Заменены полосами
  внутри участка: мастер собирает полосы сам, повторяющийся рисунок — будущий микрораппорт.
- **Одна кнопка генерации** на всё. Заменена тремя кубиками.
- **Тап по участку носка** со шторкой. Заменён деревом участков.
- **Подтверждение сброса** (вторым нажатием, окном или с «Вернуть» на несколько секунд).
  Заменено историей действий.
- **Замена удалённого цвета ближайшим по цвету** и **запрет удаления**. Выбрана замена на цвет 1
