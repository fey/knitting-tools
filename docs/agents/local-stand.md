# Локальный стенд

Как показать правку работающей: поднять стенд, собрать ссылку на расчёт, снять кадр.

## Поднять

Сначала проверить, не поднят ли стенд уже:

```
curl -s -o /dev/null -w '%{http_code}\n' http://localhost:5173/knitting-tools/
```

`200` — работать с этим стендом. Второй `npm run dev` не откажет, а тихо уедет на соседний
порт, и в отчёт уйдёт адрес, по которому правки нет.

Своего поднимать фоном и с прибитым портом — `npm run dev -- --port 5173 --strictPort`, тогда
адрес известен заранее и его не надо вычитывать из вывода. Порт занят чужим процессом —
`--strictPort` роняет запуск с ошибкой в файл вывода фоновой команды; там же vite печатает
свой адрес строкой `➜  Local:`.

Путь в адресе обязателен: `base` в `vite.config.ts` равен `/knitting-tools/`.

Стенд — это `dev`, а не `preview`. Preview слушает 4173 — тот же порт, что `webServer`
в `playwright.config.ts`, и тот подхватит оставленный сервер (`reuseExistingServer`) вместо
своей сборки: следующий прогон e2e проверит вчерашний `dist`. Проверка порта выше на 4173
не смотрит намеренно.

## Ссылка на расчёт

Параметры расчёта живут в hash (§10.1), поэтому один адрес воспроизводит ровно тот случай,
на котором правка видна. Формат и канонический пример — в шапке
`src/calculators/toe/core/hash.ts`.

Прогресс ряда в ссылку не попадает, он в `localStorage` (§10.2). Состояние с отмеченным
рядом показывают, проставив ряд прямо на открытой странице, — так это делает
`e2e/screens/toe-chart-progress.spec.ts`.

## Кадр

Экран правился — базлайны `screens` по правилу из `CLAUDE.md` и так пересняты, картинки
лежат в `e2e/screens/*-snapshots/` и едут в коммит. Назвать пути: кадр уже есть.

Состояние, которого в скриншотных спеках нет (ошибка поля, свёрнутая вводка, шторка на
отмеченном ряду), снимают разово — `page.screenshot()` одноразовой спекой или снимком
из браузерного MCP.
