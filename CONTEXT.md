# Вязальные инструменты

Калькуляторы, справочники и конструкторы для вязания носков. Словари калькуляторов — в §2 их спек
(`.scratch/toe-calculator/spec.md`, `.scratch/french-heel/spec.md`); здесь — слова, общие для сайта,
и слова разделов, у которых спеки ещё нет.

## Разделы сайта

**Калькулятор**:
Страница, которая считает расчёт мастера по введённым числам и несёт его в адресе.

**Справочник**:
Страница с готовой таблицей; считать в ней нечего.

**Конструктор**:
Страница, где мастер собирает и перебирает вариант изделия на глаз — без расчёта, по образу.
_Avoid_: генератор, инструмент, редактор

## Расцветка носка

**Палитра**:
Набор цветов, из которых собирается расцветка; цвета задаются вручную или генерируются.
_Avoid_: цвета, набор цветов, гамма

**Цвет N**:
Цвет палитры, названный своим номером в ней: «цвет 1», «цвет 2».
_Avoid_: цвет A, цвет B

**Генерация**:
Перебор незакрытого замком: цветов палитры, полос всего носка или полос одного участка —
у каждого свой кубик. Цвета и полосы перебираются порознь.
_Avoid_: рандом, «мне повезёт»

**Расцветка**:
Палитра, разложенная по носку: какие ряды каким цветом вязать на каждом участке.
_Avoid_: раскраска, дизайн, колорвей

**Участок**:
Часть носка — резинка, паголенок, пятка, стопа, мысок; раскрашена последовательностью полос,
которые вместе занимают все его ряды.
_Avoid_: часть, зона, секция

**Полоса**:
Несколько рядов подряд одним цветом палитры внутри участка; идёт один раз, не повторяется.
_Avoid_: блок, секция

**Однотон**:
Участок из одной полосы.
_Avoid_: сплошной, контраст

**Замок**:
Отметка на элементе расцветки: генерация его не меняет.

**Мастер**:
Нейтральное существительное для того, кто вяжет.
