# CLAUDE.md

Инструкции для Claude Code при работе с репозиторием. `AGENTS.md` — симлинк на этот файл.

## Обзор проекта

Калькуляторы для вязания. Первый и пока единственный — **мысок носка cuff-down**: на вход идут
начальные и конечные петли, кромка и ритм убавок, на выходе — схема и число рядов.

**Кода ещё нет, но спека готова.** Карта `wayfinder` пройдена до конца: все восемь тикетов закрыты,
её пункт назначения — `.scratch/toe-calculator/spec.md` — собран, и следующий заход строит проект
по нему. Реализации в тикетах карты нет. Стек и адрес сайта — принятые решения, а не работающая
инфраструктура: по `https://fey.github.io/knitting-tools/` сейчас 404, Pages не включён,
workflow не написан.

Куда смотреть:

| Документ | Когда читать |
|----------|--------------|
| `.scratch/toe-calculator/spec.md` | **Первым, если пишешь код.** Единый документ реализации: параметры, формулы, экран, тексты, тесты. §14 — что спека намеренно не наследует из тикетов |
| `.scratch/toe-calculator/map.md` | Первым, если правишь планирование. Назначение, словарь, принятые решения, что за скоупом |

Словарь домена закреплён в `## Notes` карты: **начальные** и **конечные петли**, **убавочный** и
**промежуточный ряд**, **интервал**, **ритм**, **кромка**, **ленточный мысок**. Эти слова идут в код,
интерфейс и коммиты — синоним значит разойтись с картой. Полный словарь — в §2 спеки.

## Стек и доставка

Vite + Vue 3 + TypeScript + Tailwind 4, статика на GitHub Pages. Версии, хостинг, деплой, причины и
отвергнутые варианты — `issues/05-stack-and-delivery.md`; когда появится `package.json`, версии
смотреть там.

Раскладка: `src/calculators/toe/` (ядро и компоненты), общее — `src/shared/`. Каталоги разведены под
будущие калькуляторы, но роутер, витрину разделов и общие layout-компоненты не строим, пока
калькулятор один.

**Ядро — чистый TypeScript без единого импорта из Vue.** Оно же держит ограничение карты: число рядов
мыска хранится самостоятельной величиной, чтобы расчёт по плотности пристыковался без ломки модели.

**Состояние живёт в двух местах.** Параметры расчёта — в hash URL, переписывается живьём через
`history.replaceState`. Прогресс ряда — в `localStorage`, одной записью `{ paramsKey, row }`; параметры
на экране не совпали с `paramsKey` — прогресса нет. Приоритет при загрузке: hash → `localStorage` →
дефолты. Прогресс в ссылку не попадает никогда.

## Язык

Карта, тикеты, спека, интерфейс, комментарии и коммиты — по-русски. Технические термины и
идентификаторы остаются как есть.

**Текст не привязывается к полу того, кто вяжет** — кнопки, подписи, пояснения, комментарии, тикеты,
карта. Домен тянет к родовым формам, но аудитория калькулятора полом не ограничена. Работает: повелительное наклонение («нажми», «потяни»), безличное («ряд считают
по-своему»), состояние вместо действия. Кнопка — «Ряд 9 готов», а не «Связала ряд 9»; баннер —
«Последний отмеченный ряд — N». Нейтральное существительное для пользователя — «мастер».
